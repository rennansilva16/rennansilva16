## 🚀 Projetos

### 🗂️ TaskFlow

O TaskFlow nasceu de uma necessidade do meu próprio dia a dia: ter uma forma simples de organizar e acompanhar minhas tarefas.

A partir desse problema, desenvolvi uma aplicação web de gerenciamento de tarefas no estilo **Kanban**, utilizando o projeto também para aprofundar conhecimentos em desenvolvimento de sistemas, organização de código e separação de responsabilidades.

**Tecnologias:** C#, .NET, Blazor, Entity Framework

🔗 [Ver repositório](https://github.com/rennansilva16/task-flow)

---

### 📄 ATS Resume Builder

Projeto voltado à criação e personalização de currículos, com foco em processos seletivos e compatibilidade com sistemas ATS.

O projeto faz parte dos meus estudos sobre **criação de produtos utilizando Inteligência Artificial**, explorando como a IA pode ser integrada ao desenvolvimento de aplicações e à criação de experiências mais inteligentes.

🔗 [Ver repositório](https://github.com/rennansilva16/ats-builder-resume)

---

### 🎮 PS Store

Aplicação web inspirada em uma loja digital de jogos, utilizando uma API externa para obtenção e apresentação de informações sobre jogos.

O projeto está sendo desenvolvido para aprofundar meus conhecimentos em **Angular, TypeScript, consumo de APIs, desenvolvimento de interfaces web e integração entre Angular e .NET**.

**Tecnologias:** Angular, TypeScript, .NET e APIs REST

🔗 [Ver repositório](https://github.com/rennansilva16/ps-store)

---

### 🐶 Bora, Doguinho!

O Bora, Doguinho! nasceu de um pedido da minha esposa: ela queria um aplicativo no iPhone que pudesse usar para me convidar a assistir vídeos de doguinhos com ela.

A partir dessa ideia simples, comecei a transformar o pedido em um aplicativo, explorando desenvolvimento mobile, notificações e comunicação entre usuários.

**Tecnologias:** SwiftUI e iOS

🔗 [Ver repositório](https://github.com/rennansilva16/bora-doguinho)
